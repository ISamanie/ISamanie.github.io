My project is a perspectice drawing trainer in html and python. It provides users with a face of a 3d cube and asks them to complete the visible faces. The user is then allowed to have their canvas graded by a local mathmatical computation written in javascript or by a request to the open ai api for more indepth feedback, the request is accompanied by a snapshot of the users canvas and context(ie asking the ai to act like an artist critiquing a student's perspective drawing). I wanted the project to be functional without the api so that part of the project is hosted on a seperate file that must be ran localy and with an api key to work properly.  

The request to the api is initated by the user clicking evaluate with ai mode selected. The web app will then call the java function evaluateAI which provides features about the canvas, as well as creating a duplicate element of the canvas with none of the UI elements for the model to critique. This is then sent to the python script via the flask library. The python script then grabs the api key and the model version from the .env file(included in .gitignore), and the request from the html app to make a request to openai. Then it returns a score and feedback to be displayed to the user.
