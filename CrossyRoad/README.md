Used Kiro ai ide to generate a html/javascript CrossyRoads clone.
I used a variety of ai models such as gemini pro, chatgpt 5.6 luna and kiro. In class I noticed 
that someone was able to get a pretty faithful recreation in one prompt by asking the model to forcably askthem questions about 
design decisions while I still had a 2d game and was struggling to implement the basic game mechanics, so I tried that strategy on 
using different models. The results were not very good so I decided to stick to my original result and improve on that. In the end I'm not
really satisfied with the result but it passes as a crossy road clone.
Game is meant to be played using arrow keys and WASD.
