My project is a simulator for a simple out of order processor. It supports only a few assembly instructions such 
as add, addi, li, add, sub, mult, beq, and bne. I wrote and tested the original data flow in system verilog and asked Claude to create the simulator and translate the .sv files in js. The site has animations for an instructions flow across its execution, and has an ai chat bot for help understanding features of the design. 
To run the program just go to https://isamanie.github.io/ click on the SuperScalar Simulator project and then on the github link on the top left. This should open the project in your browser. Secrets are hosted on the render backend.
The feature I'm most proud of are the modules themselves since this is the part I focused most of my time on, and was the most handwritten code. But Im also proud of the movement of instructions because it helps illustrate the flow of data and connections needed between modules.
